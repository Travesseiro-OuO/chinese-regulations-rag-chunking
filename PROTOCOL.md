# Pre-specified experiment protocol
Frozen before embedding, retrieval, or generation outputs, 2026-10-10 (Asia/Shanghai).

Topic: 文档分块策略对中文规章制度 RAG 问答效果的影响研究.
Four downloaded SYSU regulations (2015/2019/2020/2021 versions) form a frozen historical corpus. Official JWBQA.pdf supplies original questions and reference answers; FAQ text is excluded from index. 39 source-alignable, nonduplicate questions are retained from 241 candidates. This is a curated convenience sample, not a standard benchmark; annotator is AI, not a human domain expert. Official answers can contain procedural details outside the corpus; scoring scope is the annotated source evidence. No claim of current policy applicability.

Strategies: fixed character windows; windows with 20% overlap; greedy packing of intact article units, with overlong articles split at sentence boundaries and hard-cut only overlong sentences. All have caps 160/256/384 Unicode characters; metadata identical across strategies (document title only). No headings added only to the structural variant. Chinese normalized text offsets retained. ONNX quantized BGE-small-zh-v1.5, CLS+L2 normalization, query instruction, CPU single thread. Truncation forbidden (assert <=512 model tokens).

Primary setting: 256 characters, top-3 cosine retrieval, same deepseek-chat alias and temperature=0, max_tokens=700, identical prompt. Secondary: exact 768 source-character budget, ranked chunks consumed/truncated to same budget (metadata overhead measured, not claimed equal API token count); fixed-160/fixed-384 top3; no-context baseline; oracle annotated-evidence upper-reference diagnostic. Retrieval sweep all 9 settings under both budgets. Source budget counts duplicates; duplicated-source ratio measured. 12 deterministic questions repeated for three primary arms to assess temperature=0 instability.

Metrics: gold-span union character coverage (span alternatives take max), evidence-unit recall (>=90% covered), all-evidence success, input API token usage, latency. Generation: automated DeepSeek judge blinded to strategy, source-based correctness 0/1, completeness 0..1 and unsupported_claim flag; original reference plus gold evidence supplied. Judge assessment is not human accuracy and self-model bias is discussed. Chinese normalized character F1 is an auxiliary metric, not a semantic correctness substitute. Paired bootstrap over questions, seed20261010, 2000 replicates, 95% interval. No hyperparameter tuning on the test set or claims of significance without paired uncertainty. Question types and inclusion list frozen before running.

Isolation: non-root containers, read-only rootfs, cap-drop ALL, no-new-privileges, no published ports, internal Docker network. A fixed-destination API relay alone has a second egress network and temporary credential mount. Download/build staging needs Internet; completed experiment container has no direct Internet. Main memory limit 768 MiB / 1 CPU, relay128 MiB / .25 CPU. No host Docker socket mounted. Credential deleted after API work and relay removed.
